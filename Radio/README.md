# ریڈیو (Radio) v1.1 — Android / Kotlin

## APK بنانے کا طریقہ
1. زپ کھولیں اور اس کے اندر کی تمام چیزیں (چھپے ہوئے `.github` فولڈر سمیت) اپنی ریپوزٹری کی روٹ میں اپلوڈ کریں۔
2. اگر ریپوزٹری میں پہلے سے کوئی workflow فائل ہے تو اسے حذف کریں یا اسے اس کی `.github/workflows/build-apk.yml` سے بدل دیں۔
3. Actions ٹیب میں **Build APK → Run workflow** دبائیں۔
4. مکمل ہونے پر رن کے نیچے **Artifacts → Radio-APK** سے APK ڈاؤن لوڈ کریں۔

## نوٹ
- workflow جان بوجھ کر Gradle 8.9 استعمال کرتا ہے۔ GitHub کا ڈیفالٹ Gradle 9.x اس Android پلگ اِن کے ساتھ ایرر دیتا ہے۔
- اینڈرائیڈ عام ایپس کو فون کی ایف ایم چپ تک رسائی نہیں دیتا اور فون میں ایم ڈبلیو / ایس ڈبلیو کا ہارڈویئر نہیں ہوتا،
  اس لیے اسٹیشن انٹرنیٹ اسٹریم سے چلتے ہیں۔ اپنے اسٹیشن ایپ کے اندر «اسٹیشن شامل کریں» سے شامل کریں،
  یا `app/src/main/assets/stations.json` میں لکھیں (موجودہ چار اسٹیشن صرف نمونہ ہیں)۔
